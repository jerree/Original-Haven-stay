# 🏨 Original Haven Stay

A modern, responsive luxury hotel website built with **HTML**, **CSS**, and **JavaScript**. The website provides an elegant booking experience, allowing users to explore rooms, dining options, wellness services, meetings, and manage reservations through a clean and intuitive interface.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Interactive navigation with mobile hamburger menu
- Luxury-themed homepage hero section
- Browse hotel rooms and suites
- Filter rooms by category
- Booking management system
- Dining and restaurant showcase
- Wellness and spa experience page
- Meetings & events section
- User authentication pages (Login & Register)
- Interactive sliders and carousels
- Modern UI with consistent luxury branding

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/jerree/Original-Haven-stay.git
```

Navigate into the project:

```bash
cd Original-Haven-stay
```

Open `index.html` in your browser.
